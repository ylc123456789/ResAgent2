# 通用网页工具：实施与服务器补测

- 日期：2026-10-06
- 分支：`feat/web-search-hardening`，从 `main@0e5bb96` 开始。
- 公共 schema：23.0，不修改 Run 字段。
- 当前阶段：本地实现与确定性验证；DeepSeek 真实搜索和真实模型补测待执行，未推送或合并。

## 已实现的范围

Components 的小型 `WebSearchBackend` 接口归一化 provider 结果，默认部署新增 `DeepSeekWebSearchBackend`，显式选择仍可使用 Tavily。DeepSeek 搜索固定走官方 `https://api.deepseek.com/anthropic/v1/messages`，复用现有 `DEEPSEEK_API_KEY`，通过注入的 Runtime `ModelRequestClient` 发送单次模型请求；默认模型 `deepseek-flash`、最多4096输出 tokens、托管搜索最多5次。一次查询默认5条、最多10条、每个 snippet 最多2000字符，无分页、自动重试或多源合并。来源URL/title/page_age必须来自原生 `web_search_result`，snippet只取匹配URL的citation `cited_text`，缺少时留空，生成正文不当证据。缺少原生结果块为 `search_not_executed`；明确空的原生结果列表才是成功空结果。托管工具错误保留 `provider_error` / `rate_limited`；`max_tokens` / `pause_turn` 等未完成响应为 `incomplete_response`，不自动续传。

`WebPageFetcher` 抓取单页 UTF-8 HTML/XHTML/text，使用标准库提取文本；不运行 JavaScript、不处理 PDF 或登录会话，空正文和不支持的响应明确失败。Capabilities 保持通用 `web_search` / `web_fetch` 工具 schema，前者冻结查询回执及真实失败，后者成功时冻结 `web_page`。Scientific 按用户目标自主选择，网页和论文保持不同 kind，沿既有 Registry、reader、research index 和交付链流转；外部材料是证据内容，不是指令。

CLI 默认在已有 DeepSeek key 时启用搜索，无 key 时仅提供网页抓取，不按 Tavily key 自动回退。`RESAGENT2_WEB_SEARCH_PROVIDER=deepseek|tavily|off` 可显式选择；明确选择提供方却缺其 key，或 provider 值非法时，在文件/客户端 I/O 前报错。`RESAGENT2_WEB_SEARCH_MODEL` 独立于 `RESAGENT2_MODEL`。DeepSeek 请求上限默认60秒（`RESAGENT2_WEB_SEARCH_TIMEOUT_SECONDS`）；Tavily/抓取默认30秒（`RESAGENT2_WEB_TIMEOUT_SECONDS`），响应上限共用4 MiB（`RESAGENT2_WEB_MAX_RESPONSE_BYTES`）；均为正整数并收紧到 Run 剩余时间。

每次 DeepSeek 搜索额外占用一次共享 Run 模型调用，没有新的 Agent/Session、独立钱包或自动续传。full trace 保存请求及可取得的JSON响应；HTTP失败只保留状态和Retry-After，不保留错误正文。metadata 保存内容 hash，并关联现有 Run/Session/工具步骤；认证 header 不进入 trace。Tavily 和网页获取只占 Run 时间。公网抓取复用 Runtime 的 HTTP 地址约束：共享时间内异步 DNS、检查全部地址、固定连接 IP、保留 Host/TLS SNI、逐跳检查重定向；关闭环境代理和连接复用，拒绝非公网与混合地址。

## 官方计费核对（2026-10-06）

[官方 Web Search 说明](https://api-docs.deepseek.com/zh-cn/quick_start/agent_integrations/claude_code/#使用-claude-code-的-web-search-功能)明确：搜索会产生额外模型请求来处理搜索内容，因此产生额外模型 token 费用。公开文档未查到独立的每次/每千次搜索费率，也未明确搜索结果输入的特殊计费边界；不据此宣称搜索免费或套用其他供应商费率。

[官方模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)当前推荐`deepseek-flash`。旧`deepseek-v4-flash`仍可调用，但对应旧模型已下线，由DeepSeek-V4.1-Flash提供服务并按Flash价格计费。本轮搜索默认使用当前推荐名，主Agent模型仍按既有配置装配。

Flash人民币单价以百万token计：缓存命中输入空闲/高峰为0.02/0.04元，未命中输入1/2元，输出4/8元。高峰为北京时间工作日（不含中国法定节假日）9:00–12:00、14:00–18:00。价格会变化，以官方页面和实际账单为准。trace保留供应商返回的数值usage；Run预算计量客户端实际发送的API请求次数，不推断服务端内部请求次数或账单明细。

搜索回执的`query`保留工具输入，`provider_query`只表示提交给后端的查询；DeepSeek服务端可能改写查询，具体原生查询可从私有full trace的`server_tool_use`核对，不将请求查询冒称为引擎实际执行的查询。Runtime trace中的`response_valid`和`succeeded`表示HTTP请求返回可解析的JSON对象；最终检索成功/失败以搜索回执和Session观察为准，不能以JSON有效代替来源校验。


## 大陆服务器验收步骤

先冻结本分支最终提交，新建证据目录，不向旧 Run 追加记录。只记录密钥是否配置，不打印值，不把配置文件或 full trace/Session上传公开存储。沿现有安全方式加载部署配置后，记录 `git rev-parse HEAD`、工作区状态、9包 editable 指针、Agent/搜索模型、上下文/预算和网页上限。确保是在待验收的大陆出口执行。

先运行确定性检查，再发真实请求：

```bash
python -m pip check
python -m pytest tests apps/cli/tests -q
python -m e2e.mock_e2e
git diff --check
```

重点核对新增测试的共享模型预算耗尽/持久用量、搜索超时、无自动重试、供应商错误/非法/未完成响应、native搜索来源和引用归一化，以及 full/metadata trace 内容边界。用确定性假响应检验429与Retry-After，不主动制造大量线上请求。再确认显式 `off` 或默认无 DeepSeek key 时仍有 `web_fetch`，工具面没有 `web_search`；非法/非公网URL、PDF和可控空正文失败不产生页面工件或成功阅读记录。

真实验收使用已有 DeepSeek key，不自动注册新账号或充值。在安全配置已载入的 shell 中执行以下准备；`test` 只核对是否有 key，不输出密钥：

```bash
test -n "${DEEPSEEK_API_KEY:-}" || exit 1
export RESAGENT2_WEB_SEARCH_PROVIDER=deepseek
export RESAGENT2_WEB_SEARCH_MODEL=deepseek-flash
export RESAGENT2_WEB_SEARCH_TIMEOUT_SECONDS=60
export RESAGENT2_WEB_TIMEOUT_SECONDS=30
export RESAGENT2_WEB_MAX_RESPONSE_BYTES=4194304
export RESAGENT2_LLM_TRACE_LEVEL=full
umask 077
acceptance_root=/path/to/new-evidence/deepseek-web-20261006
mkdir -p "$acceptance_root"
```

创建两个短 Run，每个使用新的 data/trace目录。预算各 **48次模型调用/900秒**，为Scientific的动作、托管搜索和必要纠错保留空间；实际调用次数仍以持久Run用量为准。无需代码的场景可省略工作区，关闭命令和环境准备：

```bash
export RESAGENT2_LLM_TRACE_DIR="$acceptance_root/general/traces"
resagent2 run --data-root "$acceptance_root/general/data" \
  --goal "核对 Python 官方文档中 asyncio.timeout 与 wait_for 的公开行为差异。依据原始官方页面回答并给出来源，区分搜索线索、已读取正文和无法确认的信息。" \
  --max-llm-calls 48 --timeout-seconds 900 \
  --no-execute-commands --no-prepare-environment

export RESAGENT2_LLM_TRACE_DIR="$acceptance_root/papers/traces"
resagent2 run --data-root "$acceptance_root/papers/data" \
  --goal "寻找关于神经网络置信度校准与 temperature scaling 的原始论文线索，核对题名、作者和来源并概述明确有依据的结论；区分网页线索、论文题录与实际读取的全文，说明资料缺口。" \
  --max-llm-calls 48 --timeout-seconds 900 \
  --no-execute-commands --no-prepare-environment
```

第一项检查真实托管搜索返回、来源URL/引用、按需网页抓取、冻结hash、正文支持的引证及最终交付；snippet不冒称已读全文。第二项允许Scientific自主选择网页/文献工具顺序，检查网页线索与论文题录身份及kind的区别；若已有文献工具直接满足需求、未触发网页组合路径，按实际记录而不强迫工具出场。

为每个Run保存原始工具回执、Session观察、Run用量、登记工件、research index及最终意见，独立复算冻结SHA256。核对搜索模型请求与当前Run/Session/工具的trace关联，以及失败时是否保留用量/错误。完成状态不代替材料支持程度；认证、余额、接口兼容、网络不可达、超时或资料不足须按实际原因报告。没有触发的工具与失败路径如实标记，两个Run也不证明所有目标的搜索质量。

## 保留边界

DeepSeek账号密钥/余额和显式Tavily配额由部署方管理；本轮不自动注册、付费或绕过访问限制。DeepSeek别名、模型容量与托管工具兼容性由官方服务决定，不由主Agent配置推断；官方模型token价格不等于已核实搜索额外费用。公网连接只尝试首个已验证地址，失败不新增地址回退策略。普通HTML提取不保证复杂布局、表格、公式或动态内容；非UTF-8页面明确失败。网页抓取需要直连公网出口。相关性、身份核对、证据充分性和是否继续仍由Scientific判断。

# ADR-0023：外部论文导入复用 Run 材料登记

状态：accepted。日期：2026-10-03。

## 背景

单个项目不能保证服务器出口及在线文献服务始终可用。用户通过其他检索工具或手动
取得论文后，应能将资料交给某次 Run。ADR-0022 已提供单篇论文、原始 PDF 和解析
正文的身份区分，本轮在同一材料链路上补充可信用户输入，不新增独立论文管理服务。

## 决定

- CLI 接收 UTF-8 JSON 论文清单，每条至少有 title，其余元信息和本地 PDF 可选。
  Components 规范化记录并解析相对于清单的本地路径；不联网、不从 PDF 猜元信息。
  无明确 ID 时按 arXiv 来源、DOI、来源 URL 或输入快照生成稳定标识，
  保留 arXiv 版本，不按标题猜测合并。
- 创建 Run 时可带入清单；已有 Run 仅在 paused 时追加。Controller 保存输入材料
  并刷新现有 research_index，Registry 继续负责冻结、hash 和 import 来源。导入
  不调用 Agent、不创建新 Session、不回答问题、不自动恢复、不改变预算及权限。
  仍要求同一 Run 只有一个写入者，不声称并发追加或分布式事务。
- 论文条目登记为 literature_paper，本地原件为 literature_pdf。直接来源仍为
  paper→PDF→text。同 Run 的相同快照与 PDF 可复用，旧材料不改写；文件内容或
  来源不同就保留不同冻结身份。用户填写的来源不是在线服务核验事实。
- Scientific 通过既有 input_artifacts 和科研目录获知导入资料。全文 Tool 优先
  复用授权且通过 hash 校验的 PDF，按需调用现有 PyMuPDF4LLM 解析；没有原件才
  按登记的 pdf_url 下载。read_artifact 仍只读取 UTF-8 文本，OCR 继续关闭。
- 外部导入是人类入口能力，不向 LLM 暴露任意宿主路径导入 Tool。来源追溯、范围
  授权、冻结 hash 与访问日志保持现有边界；读取记录仍不参与主线资格判定。

schema 升为 22.0，旧 Run 不恢复或迁移，旧 state/session/trace 和工件保留。与 ADR-0022
的论文粒度、访问日志和按需解析相兼容，补足其暂未支持的外部导入入口。

## 限制与验证边界

第一版不解析 BibTeX/RIS，不根据 DOI 自动补元信息，不扫描文件夹、不新增向量索引
或跨 Run 缓存，不自动 OCR，也不保证用户元信息或模型结论正确。本地 PDF 需要先
放到运行 CLI 的机器上；输入只有摘要时不能冒称全文。扫描件、加密或损坏 PDF、
表格/公式提取不完整继续据实报告，失败保留原始资料。

应验证离线导入后索引可见、全文解析复用、重复导入、源文件被修改、非法清单、
跨 Run 授权、冻结文件篡改，以及 paused 追加不消费回答、不改变 Session/预算/权限。
确定性验收只证明材料与控制边界；不等于真实服务器检索或自然科研 L3 通过。
